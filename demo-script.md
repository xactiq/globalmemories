# Demo Script

## Goal

Explain the platform in under 5 minutes.

## Opening

"Most businesses are losing time and money because their information is scattered across email, files, chat, calendars, and half-connected automations."

"What we've built is a shared memory and control layer that turns all of that into something searchable, visible, and operationally manageable."

## Step 1: Explain the structure

"There are three parts."
- Memory Hub: where context becomes searchable and browseable
- Mission Control: where operations, syncs, jobs, and failures become visible
- iBuilders Lab: the implementation layer that configures this for real businesses

## Step 2: Show Memory Hub

Point out:
- memory graph
- search
- source-connected retrieval
- quick-add memory
- provenance and real source links

Line:
"This is where the business can actually find what it knows."

## Step 3: Show Mission Control

Point out:
- connector status
- job history
- audit events
- operational visibility

Line:
"This is where the business can actually trust what the system is doing."

## Step 4: Show the shared backbone

Line:
"Both products run on the same canonical memory layer, so the system shares context without becoming one giant fragile app."

## Step 5: Show commercial value

Line:
"This can be sold as a memory product, an operations product, and a done-for-you implementation service."

## Close

"The result is less lost context, better AI performance, faster retrieval, and clearer operational oversight."
