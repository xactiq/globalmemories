# Wazuh Research Sources

- GitHub repository: https://github.com/wazuh/wazuh
- Wazuh documentation use cases: https://documentation.wazuh.com/current/getting-started/use-cases/index.html
- Wazuh installation guide: https://documentation.wazuh.com/current/installation-guide/index.html

## Key takeaways from source review

- Wazuh is presented as a unified XDR and SIEM-style platform
- it includes agent + server/indexer/dashboard architecture
- common use cases include endpoint security, file integrity monitoring, vulnerability detection, configuration assessment, and incident response
- installation can be all-in-one or distributed
- it is strong, but heavier than lightweight host-only monitoring tools
