# Product Boundaries and Pricing Model

## Product boundaries

## 1. Memory Hub

### What it is
A memory and knowledge product for people and teams.

### Core value
- remember important context
- search across connected sources
- browse graph/timeline/entity relationships
- capture durable notes quickly
- retrieve documents, messages, and decisions later

### Primary buyer
- founder
- operator
- executive
- consultant
- small team
- knowledge-heavy professional

### Monetizable features
- source connectors
- advanced search
- graph views
- memory editing
- cross-source retrieval
- team sharing
- export/backup

## 2. Mission Control

### What it is
An orchestration and observability product for agent systems and workflows.

### Core value
- monitor jobs and agents
- review failures and risks
- trigger syncs and automations
- manage approvals and oversight
- audit system behavior

### Primary buyer
- operator
- agency
- dev shop
- AI workflow manager
- enterprise automation owner

### Monetizable features
- job monitoring
- workflow controls
- alerts and reviews
- governance and approvals
- audit dashboards
- role-based operational access

## 3. iBuilders Lab

### What it is
A services and implementation layer that helps customers adopt the platform.

### Core value
- setup and deployment
- vertical use-case packaging
- custom connector/workflow configuration
- consulting and managed automation

## Recommended pricing structure

## Memory Hub

### Starter
- single workspace
- local/manual memory capture
- limited search
- limited memory volume
- basic graph

Suggested positioning: low-cost solo plan

### Pro
- Google connectors
- better search and retrieval
- richer graph and entity views
- more history and storage
- export support

Suggested positioning: serious solo operator / founder plan

### Team
- shared workspaces
- role-based access
- shared connectors
- review flows
- collaboration-friendly memory model

Suggested positioning: small teams and agencies

### Enterprise
- SSO
- audit logs
- private deployment options
- advanced governance
- custom retention/compliance controls

## Mission Control

### Ops Starter
- limited jobs/workflows
- basic dashboard
- simple sync monitoring

### Ops Pro
- multi-agent monitoring
- approval/review workflows
- alerts and retries
- broader workflow coverage

### Ops Enterprise
- governance controls
- advanced audit and observability
- private environment support
- custom integrations

## iBuilders Lab revenue model

Use this for:
- onboarding packages
- implementation retainers
- vertical template packs
- custom integration fees
- advisory/architecture work

This is probably the fastest route to early revenue while the products mature.

## Packaging strategy

Best packaging direction:
- sell Memory Hub as the front-door product
- sell Mission Control as an operational upgrade
- use iBuilders Lab as services + onboarding + vertical customization

That creates:
- recurring SaaS revenue
- implementation revenue
- upgrade paths for larger clients

## Practical go-to-market thought

You likely have more leverage if you position it as:
- memory + operations for AI-assisted businesses
- or a knowledge + orchestration stack for real-world operators

That is more distinctive than selling a generic AI notes app.
