# Wazuh Sales Positioning Note

## Internal note

Wazuh itself is not the product being sold.

It is part of the trust story.

## Customer-facing framing

- Memory Hub gives you searchable business memory
- Mission Control gives you operational visibility
- the security oversight layer helps ensure the system stays trustworthy

## Why this matters

For customers, security is often an objection or trust question.

Being able to say there is a dedicated security oversight layer strengthens the story without forcing the security stack to become the main product.
